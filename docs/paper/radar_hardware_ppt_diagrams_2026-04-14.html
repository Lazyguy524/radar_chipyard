4. 权重存储与读取方式

当前实现

  • release 参数在 Chisel elaboration 阶段被读取并打包。
  • 权重被打包为 32-bit word 并写入 hex 文件。
  • RTL 内联 RadarQMLPAsyncRom，通过 $readmemh 初始化。
  • Vivado 按 rom_style="distributed" 综合为 LUT-based ROM。
  • MAC 阶段按地址直接读取 ROM word，不再需要整行权重寄存器。

不是这样

  • 不是 CPU/AXI 可运行时改写的 RAM。
  • 不是 BRAM ROM。
  • 不是从 DDR 每次推理动态搬权重。
  • 不是软件数组在硬件里运行。
准确表述：显式固定 ROM + distributed LUT 实现 + 32-bit weight word。outIdx 选择神经元行，inIdx >> 2 选择行内 4 权重 word。

7. 创新点候选

可以重点讲

  • RISC-V SoC 内嵌式雷达 QMLP 加速器。
  • 固定权重 INT8 QMLP 的显式 ROM 与 word-bank 数据流。
  • 4-lane PE/MAC 阵列降低 kernel cycles。
  • 集中式 FSM / next-value 风格重构，提高 RTL 可维护性。

谨慎包装

  • Chipyard/Rocket 平台搭建属于工程基础。
  • AXI DMA 是标准搬运机制。
  • UART-TSI 是调试/加载方式。
  • Vivado 通过是验证结果，不是创新点本身。

8. 推荐结论页

当前硬件系统已完成从软件 QMLP 模型到 RISC-V SoC 内嵌式 RTL 加速器的实现闭环。模型采用 21->64->32->2 INT8 结构，权重在 bitstream 生成阶段固化为显式 distributed ROM，运行时通过 outIdx/inIdx 地址访问、32-bit 权重 word 和 4-lane PE 完成定点推理；中间激活采用 64-bit word-bank 缓存。

板级验证中，1000 组 large golden 与 54 组 boundary cases 全部通过，QMLP kernel latency 为 1301 cycles，约 26.02 us @ 50 MHz。该结果可支撑论文中“面向低功耗边缘雷达检测的 RISC-V SoC + 专用神经网络加速器设计”的硬件主线。
