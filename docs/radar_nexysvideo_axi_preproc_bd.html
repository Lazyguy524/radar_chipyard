当前怎么看“功能通过”

  • 软件先配置 MODE / PARAM0 / PARAM1 / CTRL。
  • DMA 跑完后，软件用黄金参考逐字比较 RX buffer。
  • 同时检查 IN_BEATS / OUT_BEATS / FRAME_COUNT 是否和期望一致。

当前怎么看“链路层次”

  • 控制面：CPU -> System Bus -> AXI4 MMIO -> Bridge -> DMA CSR / Local CSR。
  • 数据面：DDR -> MM2S -> AXI4-Stream 算子 -> S2MM -> DDR。
  • 因此后续加新算子时，最核心的改动通常只落在中间这段 Stream 处理链。
