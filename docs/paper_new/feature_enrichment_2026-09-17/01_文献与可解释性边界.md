# 本轮读什么、可以支持什么

1. **Scheiner等，Radar-based Feature Design and Multiclass Classification for Road User Recognition**：[作者预印本](https://arxiv.org/abs/1905.11256)、[PDF](https://arxiv.org/pdf/1905.11256)。优先读III-A：除了基础极值/均值/离散统计，还讨论空间协方差、簇内几何分布及静止/运动点比例；II-B强调少量反射点的增减会让特征剧烈变化。此处只借鉴特征类别与问题动机。本实验的跨度归一化、量化及0.5m/s阈值是本轮设计，不能称逐项复现该论文。预印本上传为2019，前期资料所称2018与正式会议记录须按原书目区分，不把上传年当实验年份。
2. **Weinmann等，2017，Geometric Features and Their Relevance for 3D Point Cloud Classification**：[出版页](https://isprs-annals.copernicus.org/articles/IV-1-W1/157/2017/index.html)。这项LiDAR研究将点采样、邻域和特征关联一起考察，支持“特征作用依赖观测条件”的实验组织。不能把其三维几何结论直接当作二维汽车雷达效果证明。
3. **Weinmann等，2015，Semantic point cloud interpretation based on optimal neighborhoods, relevant features and efficient classifiers**：[KIT作者机构记录](https://publikationen.bibliothek.kit.edu/1000063185)，DOI 10.1016/j.isprsjprs.2015.01.016。用于了解如何围绕邻域、特征与分类器进行分解对照；本轮没有重做它的邻域搜索或跨模型筛选。

“可解释”分三层：公式及物理含义可解释；同外轮廓/均值而不同内部散布的输入可以用具体点簇展示；真实分类贡献由相同预算重训、等维冗余对照和条件错误变化检验。第三层必须有数据，前两层不能代替分类实验。当前没有独立留出域，不能通过反复读开发集、再补公式来追认泛化或原创性。
