# 新增量的值域与点数效应

设一个观测内有N个标量a，最小值m、最大值M、跨度L=M−m，均值μ=Σa/N。这里使用观测内总体方差，不把有限点样本方差当作真实目标分布的无偏估计。

每个a满足 `(a−m)(M−a)≥0`。取均值并整理得到 `E[a²]≤(m+M)μ−mM`，因而 `Var(a)≤(M−μ)(μ−m)≤L²/4`。故非零跨度下 `4Var(a)/L²∈[0,1]`。x/y的协方差由Cauchy–Schwarz不等式有 `|Cov(x,y)|≤sqrt(Var(x)Var(y))≤LxLy/4`，所以本轮的协同分布量位于[-1,1]；它与除以标准差乘积的Pearson相关系数不同。

均值在最小/最大值之间，因此 `2(μ−m)/L−1∈[-1,1]`。近零径向速度比例是计数除以N，处于[0,1]。这四种界允许统一以127为满量程，用有理数取商/余数执行ties-to-even，无需由开发集搜索新输出尺度。零跨度定义为0并披露，不能解释成0恰好表示某一种真实目标。

以平方和Q=Σa²、和S=Σa表示，量化前比值为 `508(NQ−S²)/(N²L²)`。所有输入INT16、N≤511；保守分子界 `508×511²×65535²` 小于2^63，因此当前实现选择INT64。这个保守存储选择不等于已经完成最小位宽分配或FPGA综合。

**单点与两点是关键反例。** N=1时跨度为0；N=2且两个值不同时，方差恰为L²/4，所以归一化方差恰为1，不论两点距离是多少。这时变量主要表达“是否有非零跨度”，不能告诉我们更细的目标内部形态。对x/y两点，归一化协方差也仅是±1或零，反映连线的符号关系，不足以恢复形状。

随着N增长，内部采样分布才可能影响相同外跨度内的离散程度。范围本身也是样本极值，因此还存在点数依赖和极端点敏感性。为便于阅读，另在训练完成后用固定种子、每格2000次、N=1/2/3/4/8/16/32/64对均匀、中心聚集、双峰理想分布做无标签模拟；它只解释表示，不参与训练、阈值或选型，也不把三种理想分布当作雷达类别。[模拟图](figures/point_count_degeneracy.png)。

原点数INT8字段的尺度使N=1和N=2均编码为0；新增二阶量有时可能补充这种观测支持线索。若想把这一效应与内部形态信息完全分开，仍需独立的“只改点数编码”控制。本轮已报告按准确N1/N2/N≥3的结果，但没有额外训练该控制，不在结论中补写未经验证的因果链。
