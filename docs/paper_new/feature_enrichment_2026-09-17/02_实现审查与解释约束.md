# 训练前实现审查

本轮五组15条在训练前确定，新增两组7个量，并保留23维冗余输入对照。增加输入列会增加参数，不能把所有收益直接称为新增物理信息作用；combined23必须另外超过这个等维对照。新增列及冗余列初始权重都为零，原隐藏层一致，但后续参数化/优化仍不同，故结论限定为受控重训关联。

接近最高综合分0.1个百分点的已通过候选，复杂度优先级具体按新增每点乘积数排序（速度/RCS组2、几何组3、合并组5），再看网络维数与分数。它是本轮透明的简洁性偏好，不将每点乘法、每簇除法和神经网络MAC混成一个未经测量的时延；另外完整公开各类运算与质量，不称全球成本最优。

真实重建从旧observations.csv恢复同一序列、传感器、轨迹、帧。每条重核原点数、标签多数规则、历史数量和先前时间跨度；每个新视图前16列必须与旧缓存相同，新增7列来自同一视图的点，不能把完整簇的统计量偷渡给删点视图。合成少点保留相同历史且只抽当前1～2点；自然少点不更新历史。没有新检测/关联或时间对齐能力。

数学边界：所有输入为INT16，N≤511；保守采用 `508×511²×65535² < 2^63` 的分子上界，分母最大 `511²×65535²`。有理数余数比较使用 `r > denominator-r`，避免比较时额外乘2溢出。QAT/C推理另核INT32累加和INT64乘积，C批次步长依据真实维数。

几何归一化对无量化截断/饱和的平移及正比例缩放不变；RCS归一化方差与对称位置对正仿射变化不变。整体重复观测会保持这些分布量，但不会增加独立信息；点数仍在原16维中。两点归一化方差达到上界不代表可靠的物理结构判断，需按点数公开结果。0.5m/s径向近零阈值固定、不过度解释成目标静止。

未采用历史年龄/位移作为新分类输入：先保留相同历史规则和模型，减少变量混杂。它们仍用于解释旧条件回退及列明适用边界；不是认为历史问题已解决。
