# 如何解释这些数据

1. **先解释输入差异。** 合成点簇保留相同N、旧均值/跨距/距离代理和RCS统计，使原16维逐整数相同；改变内部点分布或速度/反射分布后新增描述不同。这些反例无类别标签，只证明表示能够区分某些输入，不证明某个类别应是什么。[反例原值](../../../logs/feature_enrichment_20260917/synthetic_preflight.json)。

2. **再解释统计分布。** [两类训练分布](../../../logs/feature_enrichment_20260917/train_feature_distributions.csv)与[按精确保留点数分组的真实少点训练分布](../../../logs/feature_enrichment_20260917/explanation/natural_train_by_N_and_class.csv)给出均值、分位数、零值和上界占比。两类均有重叠时，不能把一个特征直接写成确定分类规则；跨序列/传感器的因果解释没有在本轮建立。

3. **最后检验分类效应。** 两组单独加、一起加和等维冗余对照用于区分条件作用及交互。修复/新增错误案例固定取首三条并附特征值，不事后挑最好看的例子；单个神经网络判断不能靠查看特征值就得到可靠因果归因。本轮重训分解到“几何组/速度RCS组”粒度，没有分离每一个新增维度的独立贡献。

特别的替代解释：原点数编码对N=[1,2,3,4]得到[0, 0, 1, 1]。单点二阶散布为0；两点且有非零跨度时归一化方差为127。这是原尺度选择造成的分辨率限制，不自动等于程序错误。因此新增描述可能部分恢复丢失的低点数线索。已单列[各模型N1/N2/N≥3指标](../../../logs/feature_enrichment_20260917/explanation/performance_by_exact_low_N.json)，本矩阵没有额外训练“只修正点数”的控制，不能据此独断收益全部来自形态。

确定性首100000条保留训练样本中，同16维编码的后续观测为1058条，与该编码首条标签不同的为0条，其中新增量同时不同的为0条。这是有界描述性检查，不是所有配对数，也不证明这些冲突都能分类解决。[口径与数值](../../../logs/feature_enrichment_20260917/explanation/training_collision_diagnostic.json)。

下一步若专门处理历史混合或点数编码，应另冻结一个单变量方案及预算，保留这里的负结果，不能边看开发分数边变换主线。
