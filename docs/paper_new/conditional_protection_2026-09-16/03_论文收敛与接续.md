# 论文怎样收口，后续怎样避免偏离

**本阶段停止扩展训练技巧，冻结普通训练 A、扰动训练 B 和正确判断保护 C 作为三种代表性对照。** D 的完整结果保留用于组约束负结果，不选一个最好 seed 替代方法结论。停止探索某个技巧并不意味着必须删掉它的分析价值；“未满足全部门槛”也不等于没有任何收益。

## 从本轮得到的具体反馈

正确判断保护 C 将三个 seed 的新引入错误从 B 的 536/403/439 降到 250/314/365；近距离自然少点组的平均 F1 从 B 的 96.3038% 回到 96.9846%，接近 A 的 97.2008%。但中心保留一半从 B 的 97.0093% 降到 96.6675%。[结果和失败门槛](02_结果与反思.md)

因此，“旧正确行为完全保住，同时所有困难条件也不掉分”还没有实现。观察与保护旧边界和适应新输入之间存在取舍相符，但不能仅凭本轮就断言这是不可克服的理论上限。尤其 train 保护只覆盖原保留 K7，而自然少点并未训练；模拟删点和真实少点不是同一分布。下一步即使继续算法，也应先核实输入/历史和真实训练覆盖，不能只给蒸馏损失继续加系数。

## 冻结可以写的论证链

| 论文问题 | 已有证据 | 可以写的结论 | 不能越界的说法 |
| --- | --- | --- | --- |
| 近似是否影响判别 | 统计四组、点数/形态干预、多 seed | 数值精确度与分类收益不单调，收益依条件而变 | 精确矩必然优于代理 |
| 表示与精度怎样结合 | 输出映零、线性/根号对照、固定权重精度实验 | 输出尺度可掩盖算术误差，最低精度依表示和条件 | Q16 对任何输入都足够 |
| 稳定性是否只靠更多算子 | 简单强基线、扰动和保护训练、真实少点审计 | 训练覆盖解释了部分收益，复杂统计必要性尚未证明 | 数据增强/蒸馏本身是新算法 |
| 怎样实现并验证 | 单遍共享 C、逐层整数对拍、既有 SoC/板测 | 计算依赖与正确性已有实现基础；当前候选成本先作结构说明 | 把新 C 指标接到旧位流称完整新板测 |
| 结果能推广到哪里 | 原始过滤、序列划分、GT-track/K7 审计 | 明确任务与覆盖范围，公开关键组退化 | 二分类 F1 高就证明无偏，熟悉 validation 是独立 test |

算法章节可围绕上述假设、控制变量、结果与取舍组织；硬件章节解释为什么保留/不增加某类共享运算，再接具体结构、调度和实测。状态机图和接口表是支撑材料，不能替代研究问题与设计依据。

这给论文提供了可写、可审查的实验链条，尚不构成对毕业充分性或算法原创性的保证。已有 RISC-V SoC、事件统计、DMA/IRQ/WFI 和门控的原证据继续独立成立，不因本轮算法探索而推倒，也不能被挪来冒充新权重的板测结果。

## 后续只补关键缺口

1. **评价闭环。** 当前本地历史二分类有效序列都已进入 train/validation/历史 test，额外五个序列没有所需目标轨迹点。真正的独立确认需要新的适用数据或另行严格设计的评价研究；本轮不重命名旧数据充数。
2. **实现闭环。** 在确定任务适用范围和代表方案后，将特征输出尺度、网络参数、软件、位流绑定起来验证。A/B/C 的新参考使用相同 proxy 结构和 21 维网络，仍不等于旧位流只换权重就能正确使用；逐特征量化尺度必须配套。
3. **论文闭环。** 原始数据处理与近似定义→条件实验→共享实现→同配置板测，每项主张对应证据。独立确认、上板资源/性能未补齐的条目保留待测，不靠继续增加训练次数填补。

如果下一轮任务不能说明它在这三项中的位置，应先记录理由再决定是否执行。新证据可以改变假设和路线，但不能静默改掉[用户原问题](research_contract.json)或既有负结果。
