## 使用 C 候选

解压 [candidate_c_bundle.zip](candidate_c_bundle.zip)，进入任一方法/seed 目录：

```bash
gcc -O2 -std=c99 candidate.c -o candidate
./candidate example.int16le
```

与同目录 `example.json` 核对。输入每点 x/y/补偿径向速度/RCS 四个小端 signed int16 Q8.8，1…511 点；上游 GT-track/K7 处理不在程序内。教师、分组信息只用于训练，部署网络不增加这些输入。六个 C 参考可运行不等于六个算法都通过推广门槛。

## 实验复现约束

环境沿用 Python 3.10、NumPy 1.26.4、PyTorch 2.4.1 CPU、h5py 3.11、GCC。`preflight.py` 只用 train 准备教师与分组并检查数值；`train.py` 固定六条训练；`evaluate.py` 按冻结标准评价；`build_candidates.py` 对拍完整整数实现。`run.py` 按顺序运行，拒绝覆盖原输出。

重跑需建立新的实验目录和计划，保留本轮冻结结果。仅重看结果用[结果文档](02_结果与反思.md)与日志 summary；只重生文档用 `report.py`，但冻结后如改写报告，需同步新的审计版本。当前审计结果见 [validation.json](validation.json)。
