# 设计账本：主线、反思与变更记录

本文件保留研究决定，不用新结论覆盖旧理由。2026-09-16 用户批准继续两种有约束训练，并要求反思、反馈、保存设计思想与 Git 备份。

## 不随实验结果偷偷改写的主问题

**在点数和目标形态变化时，哪些近似会损害分类稳定性？能否针对这些误差，用更合适的统计表示、精度分配和共享计算结构，获得优于现有实现的质量—成本取舍？**

任务目标是完整硕士论文的可检验证据链：条件误差→必要的表示/训练修正→共享定点实现→同配置实际质量与成本。训练保护约束是检验统计硬件是否必要的一个步骤，不能让主线变成无止境追求验证集分数。21 维、某个精度、某个训练技巧和新增 RTL 都不是必须得到的答案。

以下边界持续有效：原数据/模型/位流保留；验证域探索与独立确认分开；最终性能按上板实测；板卡有资源余量，不虚构“装不下”；标准 RISC-V SoC/IRQ/WFI 为系统内容，原 custom arithmetic ISA 不恢复为创新；负结果和组退化不能隐藏。

## D01：本轮为什么做正确判断保护

证据：[35 条训练的评审](../mechanism_convergence_2026-09-16/03_评审与收敛决定.md)显示定标＋扰动训练比新增矩统计更稳定地改善少点输入，却牺牲部分近距离/历史充分组。先测试能否在同一简单表示上减轻这种损失，再决定是否值得加统计算子。

方案一只在原训练输入、旧模型预测正确时施加蒸馏约束；旧模型错的例子与人工减点例子不受该约束。方案二增加按原观测支持分组的训练损失分配。两者各三个 seed，六条为上限，采用相同单视图抽样/学生前向次数；教师离线计算单独记账。所有损失系数提前固定，不从 validation 搜索。

主要风险：保护的只是 train 上旧模型正确行为，不能保证 validation 不退化；完整 K7 上的保护可能不能覆盖自然少点；分组最坏训练损失不等于最坏泛化风险；蒸馏可能妨碍修复旧决策边界。因此需要同时记录新引入错误、修复错误、整体指标、关键组和其他支持充分组，不能只报一个平均值。

## D02：查重后的定位修正

“保护旧模型正确样本、减少负翻转”已有直接研究：Yan 等 CVPR 2021 的 Positive-Congruent Training / Focal Distillation。本轮属于借鉴此思想的受限对照，不宣称原创训练方法；我们对 clean 视图和正确教师做掩码，具体公式以代码为准，并非原文的完整复现。[会议原始记录](https://openaccess.thecvf.com/content/CVPR2021/html/Yan_Positive-Congruent_Training_Towards_Regression-Free_Model_Updates_CVPR_2021_paper.html)

按预定义组优化风险已有 group DRO；Sagawa 等也明确指出最坏训练损失改善并不自动带来最坏组泛化改善。本轮不把已有思想重新命名为新算法，保留与普通增强的等预算对照。[原始论文](https://arxiv.org/abs/1911.08731)

这次查重反馈直接进入论文边界：有价值的候选贡献应由雷达条件误差、表示/位宽选择与实现证据支撑，不能只靠组合已有损失函数。

## D03：评价域与确认资料

历史二分类清单包含 113 个 train、27 个 validation、13 个 test 序列，共 153 个；RadarScenes 本地目录列有 158 个。缺席清单的 5 个序列仅作为标注覆盖与历史使用审计对象，不看模型分数、不按结果挑选。缺席一个清单不等于从未用于其他训练或调参，也不意味着具有当前任务的可用标注。

即使本轮不能形成独立确认集，探索实验仍可按计划执行，但不升级为最终泛化证据。旧 test 只允许查清单身份，不新增模型评价。
