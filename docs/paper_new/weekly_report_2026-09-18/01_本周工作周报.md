# 周报｜雷达点簇分类的特征表示与软件方案收敛

汇报日期：2026-09-18；工作统计截至2026-09-17。覆盖本自然周2026-09-14～2026-09-17，9月12日的PMU实施等作为前期基础，不重复记为本周新增完成。

## 可直接提交的简版

本周围绕“点数和目标形态变化下，统计近似与输入表示如何影响分类稳定性”开展软件分析与对照实验。首先恢复并核对原训练资料、模型及导出参数，复核数据划分、历史累积规则和量化尺度；恢复原先过滤的474,582条真实少点训练观测，完善常规输入、删点扰动及真实少点的评价范围。

在固定模型隐藏层、数据划分与训练预算的条件下，完成两种统计表示与两种少点覆盖策略的12条训练，并分阶段完成特征删减、信息补充和8～36维双向实验，共60条维度相关训练。结果表明，原21维存在冗余，但继续压缩到本轮8/12/15维组合会降低综合表现；16维基础上补充几何及速度/反射分布的23维候选，综合Macro-F1由96.763%提升至96.960%。继续增加分位数描述未形成稳定替代优势，当前保留23维软件候选，同时保留旧常规主基线与困难条件备选。

完成软件参考实现、整数一致性检查、失败案例整理与Git/Obsidian归档。最新33个模型共9,105,294次原始点至特征和分类输出的C参考核对零差异。当前结果仍存在少点细分条件退步，且开发数据已反复用于选型，不能写成独立泛化结论或新增板级收益。下一步拟固定候选与评价流程，诊断历史时间跨度及坐标位移的影响，并准备不参与调参的独立序列确认。

## 代表结果与判断

下表来自最新双向实验中的同一开发域评价；16/23维为经过输入及预测重放核验的冻结模型。每项为三个种子均值，单位为百分数。

| 所测表示 | 常规Macro-F1 | 五条件综合Macro-F1 | 当前判断 |
| --- | ---: | ---: | --- |
| 8维基础量 | 97.336 | 95.780 | 本次紧凑组合损失明显 |
| 16维基础表示 | 98.143 | 96.763 | 保留为简化对照 |
| 23维分布补充 | 98.491 | 96.960 | 当前软件候选，仍有局部缺口 |
| 24维点数支持补充 | 98.479 | 96.966 | 几乎持平；旧局部问题未可靠解决 |
| 28维四分位宽度 | 98.606 | 97.060 | 平均最高，但种子/类别/少点分组退步，另有排序成本 |
| 32维两组分位特征 | 98.526 | 97.021 | 未形成稳定替代优势 |
| 36维完整分位补充 | 98.609 | 97.011 | 未形成稳定替代优势 |

五项综合等权包含：常规、均匀保留四分之一（先平均三次固定抽样）、中心保留一半、真实少点当前帧、真实少点加历史。Macro-F1为两类F1的宏平均；它不同于准确率。来源：[完整结果CSV](证据/dimension_results.csv)。

值得保留的机制发现：按本轮固定分位定义，输入总点数N=1/2时，新增分位组由已有特征决定，没有增加独立信息；N=3时部分新特征间仍有精确依赖。这里的N是实际送入分类器的总点数，可能包含历史，不能等同于当前一帧回波数。[E07](05_证据索引.md#e07)

## 当前风险与下周安排

1. **候选不等于正式替代。** 23维对旧A仍有116条/19序列的紧凑少点组退步；24维虽然独立通过旧门槛，该组仍净多错3/4/0条，只是一个种子打平。保留旧A常规主基线、旧B困难条件备选，不自动切换模型。
2. **独立泛化尚未确认。** 当前validation已用于多轮开发，历史test也有选K记录。需要核查新序列身份并冻结独立确认协议，不能把熟悉数据重新命名为测试集。
3. **历史规则限制解释。** 同序列/传感器/真值轨迹累积最多六个先前保留观测加当前观测，真实少点不更新历史；当前没有时间过期或坐标对齐。因此拟检查跨度/位移与错误的关系，先做诊断，不直接宣称因果。
4. **成本先按实际口径报告。** 软件可报告MAC、乘积、比值与存储；FPGA收益待同配置测量。本周不虚构板卡资源耗尽，也不以软件分数代替系统性能。

下一阶段计划：固定软件候选和证据包 → 有界历史诊断 → 准备独立序列确认。若发现数据或实现问题，先修正并重新审计；不为了提升开发分数无限扩维、换种子或修改接受门槛。
