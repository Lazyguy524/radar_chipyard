# 5页、5分钟：直接交给PPT制作端

主题：**雷达点簇分类：本周特征表示与软件验证进展**。

受众：了解课题大方向、未看过实验细节的课题组。不给A/B/C等内部编号增加记忆负担，口头称“旧常规基线”“困难条件备选”。共5页，建议时间30/55/90/65/60秒；不额外加纯封面、目录、感谢页或隐藏附录。

## 第1页｜本周：补齐算法选择的依据（30秒）

**投影正文：**

- 面向雷达点簇的轻量分类，衔接既有Feature21＋QMLP系统
- 本周重点：数据复现、条件评价、特征增减对照
- 核心问题：点少或分布变化时，哪些统计量值得保留？

**画面：** 一条简单流程“雷达点簇 → 统计特征 → 整数分类器”，突出中间的特征表示；不画SoC细节。页角标日期2026-09-18，姓名留“汇报人：待填写”。

**口头讲稿：**

这周主要补算法选择的依据。现有系统已经有特征提取和分类流程，但原来的21维是否都有必要、面对少点输入是否仍然可靠，需要用实验解释。所以这周先核对训练资料，再把常规输入和困难输入一起评价，最后做特征删减与补充。今天只讲这条软件主线，硬件对比和具体公式留到后面专题汇报。

**来源备注：** E01、E04～E07。

## 第2页｜先补数据，再统一比较条件（55秒）

**投影正文：**

- 核对原始资料、模型与量化尺度；恢复 **47.5万条真实少点训练观测**
- 真实少点：当前观测本来只有 **1～2个雷达点**
- 每个特征方案 **3个种子、13种评价条件**，同时看总体与分组表现

**页脚必须可见：** 当前为开发集评价，独立泛化待确认。

**画面：** “常规输入 / 人工删点 / 真实少点”三个输入卡片汇入同一评价流程。1～2点的示意只能画无标签点，不能伪造雷达截图或物体类别示例。

**口头讲稿：**

先处理数据覆盖问题。原流程过滤了一批当前只有一两个点的观测，这类输入和从密集点簇里人工删出一两个点并不完全一样。我们恢复了约47.5万条这样的训练观测，并单独评价只用当前帧和加入历史两种情况。比较时保持数据划分、隐藏层和训练协议一致，每组用三个随机种子，观察13种输入条件。现在这些数据已经反复用于开发，所以今天报告的是方案筛选结果，独立数据上的表现还需要确认。

**来源备注：** E01、E04、E07。精确训练数474,582；原保留训练357,780。原保留开发观测80,450，真实少点开发观测97,734；这些精确数留在备注，不挤进正文。

## 第3页｜删减与扩充：更多维度不保证更好（90秒）

**投影正文：**

- 三阶段完成 **60条维度相关训练**，所测范围扩至 **8～36维**
- 16→23维：综合分 **96.763%→96.960%**，提高 **0.197个百分点**
- 更小组合损失明显；28维平均最高，但有局部退步

**页脚必须可见：** 开发集；三种子均值；五类条件Macro-F1等权综合。不同维数对应不同信息组，非纯维数单因素扫描。

**口头讲稿：**

特征部分分了三步。先从21维删重复项和部分派生项，再从16维补充几何、速度和反射值的分布描述，最后把范围扩大到8至36维。三阶段一共完成60条训练。图里只放五组代表结果：8维明显下降，16维是简化基准；补成23维后，综合分提高了0.197个百分点。28维的平均分更高，但不是可以直接选它，因为一个种子变差，部分少点分组和类别召回也下降，还需要增加排序。继续到36维也没有形成稳定优势。因此我们现在看的是质量、局部退步和计算代价的共同取舍，而不是只追求维数更大或者最高平均分。

**来源备注：** E05～E07。60=12+15+33；最新阶段复用的六个模型不重复计数。28维相对23维未舍入增益0.0991296个百分点，不能把显示值相减后说它满足至少0.1个百分点的要求；它另有种子/类别/分组失败，不是仅因舍入被否决。

## 第4页｜阶段结论：保留23维候选，尚未全面替代（65秒）

**投影正文：**

- **暂保留23维软件候选**：补充有解释意义的分布信息
- **仍有少点细分条件退步**：旧常规基线和困难条件备选继续保留
- 最新33模型约 **910万次C输出核对零差异**；独立泛化及新硬件收益待验证

**页脚必须可见：** C核对是模型×观测/视图次数，不是独立样本数或板测。

**画面：** “阶段性保留 / 仍需验证”两栏。不要绿色勾选“算法最终最优”“全面提升”或“已部署”。

**口头讲稿：**

目前收口到23维软件候选。它是在16维基础上增加七项分布描述，能解释外轮廓相似、内部点分布不同的情况；但具体公式今天不展开。需要说明的是，23维也不是所有条件都更好，部分真实少点和细分组仍有退步，所以旧常规基线与困难条件备选保留。实现方面，最新33个模型已经完成约910万次完整C参考核对，特征和分类输出一致。这证明参考实现的一致性，不能代替独立泛化或板级验证。

**来源备注：** E06～E08。精确核对次数9,105,294；原23维相对16维真实少点当前帧−0.266个百分点；对旧常规基线仍有116条/19序列组退步。细节进入个人问答，不做隐藏PPT页。

**下方一句总结：** 本周从“21维沿用经验”推进到“有限实验支持的特征取舍”。

下一步先固定候选和评价流程，把已经完成的实验整理成可复核的论文证据。软件上更值得继续检查的是历史累积：现在使用同一真值轨迹的既往观测，没有时间过期和坐标对齐，所以点多不一定代表目标单帧形状更可靠。先做有界诊断，再准备真正未参与选型的独立序列确认；若暂时没有合格的新数据，会明确保留这个缺口。硬件等配置匹配后再验证。本周最主要的进展，是把特征选择从经验设置推进到了有对照、有代价和有适用边界的阶段。
