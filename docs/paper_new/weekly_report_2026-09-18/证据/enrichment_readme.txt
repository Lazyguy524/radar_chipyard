新增量描述的是“相同外轮廓内点如何分布、径向速度如何分布、反射值更偏向哪一端”。先用同16维输出的具体反例证明表示差异，再用匹配训练验证是否真有分类价值；物理解释不自动等于分类增益。

单点和两点的几何描述容易退化；旧点数编码又将N=1/2都量化为0，因此新增量可能同时提供点数不足的间接线索，不能把全部收益归因于更准确的目标形状。[低点数解释](06_数据解释与反例.md)明确保留这个替代解释。
