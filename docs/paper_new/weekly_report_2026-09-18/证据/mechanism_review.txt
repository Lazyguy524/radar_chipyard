# 评审与收敛决定

**本轮算法研究得到的是一个更明确的取舍问题，尚不是已验证的最终硬件最优解。** 35 条完整训练已经足够否定“统计越精确、特征信息越多就一定越稳健”的简单推断。接下来不应继续无目标增加算子、位宽和 seed。

## 1. 得到的五点认识

**点数相同，丢掉哪些点依然重要。** 原代理三个共同 seed 在原始紧凑形态组，均匀保留一半 F1=96.3697%，中心保留一半为 92.5875%，相差 3.7822 pp。仅修正均值减轻这一差异，不能消除；增强后原代理差值缩小到 0.4494 pp。这个实验控制保留点数，支持关注形态/分布变化；并不证明实际遮挡会产生相同效果。[逐组数据](05_分组收益与回退.md)

**前端精确度与判别信息要分开。** 原分档均值的数值衰减已被证明，但训练后的网络能部分适应；只修正均值在中心删点有收益，在均匀四分之一不优。空间矩再加入后也不是收益叠加。不能把“更接近浮点”直接写成“分类更好”。[五 seed 机制拆分](02_结果与所得认识.md)

**输出量化会隐藏算术误差，但解开它也不保证分类收益。** 方差输出映零比例很高，开平方编码显著恢复非零值；在相同三 seed 中，原始输入有小幅改善，均匀四分之一反而从共享矩的 95.3177% 降到 94.9960%。这支持完整检查“统计定义→数值范围→INT8→分类”链条，削弱“只要细化输出就能修复稳定性”的假设。[编码专项](../moment_encoding_2026-09-16/README.md)

**本轮更稳定的收益来自训练覆盖，同时存在条件代价。** 原代理的三个均匀四分之一重复均改善约 1.32–1.34 pp，三个 seed 均改善。真实被过滤且没有原保留历史的 29,596 条观测从 88.3752% 到 93.8933%；但真实少点中距离≤20 m 的组从 97.2008% 到 96.3038%，有六个历史观测组从 98.1267% 到 97.7266%。这些是相同观测/相同 seed 的比较；组间因果、差值统计显著性和新数据上的重复性另论。不能用平均收益遮住回退。[分组对照](05_分组收益与回退.md)

**精度选择必须知道输出表示和共享结构。** 原粗矩输出下 Q12/12 五 seed 全通过，细线性/平方根编码仅 2/3 seed 通过；统一 Q16/16 在这里的受检表示全通过。不同路径各取最低精度，可能新增倒数读取和重复均值计算，未必比统一精度便宜。所有发布 C 参考仍为 Q24，未伪装成低位宽已上板。[精度表](02_结果与所得认识.md)

## 2. 目前保留与停止的路线

| 路线 | 阶段决定 | 原因 |
| --- | --- | --- |
| 原代理＋逐特征定标 | 保留为低计算基线 | 没有逐点空间二阶乘法，其他方案必须证明有必要超过它 |
| 原代理＋扰动训练 | 保留为主要确认候选，三个 seed 全留 | 多条件/自然少点改善，但部分组回退，尚非全面替换旧模型的发布版本 |
| 只修正均值 | 保留为机制对照和次级候选 | 中心删点有支持线索，收益有条件，不足以宣布普遍更优 |
| 共享二阶矩 | 保留已实现 C 参考，暂停新 RTL | 原始和增强对照均未建立稳定全面优势；新增逐点乘法需有明确收益 |
| 更细线性/开平方输出 | 保留本轮结果，不再扩展搜索 | 能恢复表示分辨率，尚未转化为稳定分类优势；根号有额外成本 |
| Q8 倒数 | 不作为本轮通用候选 | 多表示、多 seed 条件门槛失败 |
| Q16 统一倒数 | 作为数值实现候选，未发布硬件 | 当前所测条件过门槛，仍需实际同配置资源、时序、板测 |
| 随机森林/后向删维 | 保留已有 RF 解释，暂不启动全搜索 | 已有数据表明训练覆盖和表示链条更值得优先解决；21 不被宣布最优 |

保留全部模型是为可复核，不是建议同时部署多个网络。本轮没有根据最好 seed 选一个“冠军”覆盖旧权重，也没有自动按距离/历史切模型。新门控策略若提出，需要独立计划和 train 内阈值学习，不能直接抄 validation 上的组界限。

## 3. 把研究问题收窄成可完成的算法目标

可以表述为：**在给定观测支持与定点实现条件下，选择统计表示、训练覆盖和共享精度，使少点/形态变化条件的分类风险下降，并约束原有效输入组的退化和实际实现成本。**

形式上令输入变换为 `T_c`、表示为 `φ_s`、输出量化为 `Q_b`、分类器为 `f_θ`，研究 `R_c(f_θ(Q_b(φ_s(T_c(P)))))`，不只看总体风险。实施成本应写成共享计算图 `C(G_s,b)`，不能简单把每个特征的独立成本相加；观测支持可包含当前点数和可用历史，不能只有融合后的 N。最终候选应同时满足预先给定的关键组退化上限、原始数据质量下限和实测成本预算。当前数据支持提出该目标，尚未证明已找到其最优解。

下一次实验应先解决两个独立缺口：一是冻结不再参与调参的确认序列或新增数据划分，完整核验与现有 train/validation/历史 test 的重合；二是限定一个用于保护原有效组的训练约束，与本轮固定增强强基线做等预算对照。若仍只能在熟悉 validation 上探索，必须继续标注探索性。固定增强比例、距离阈值或更复杂教师损失都不能未经新计划就一路试到满意。

本轮不继续加入 LSTM、全后向消除、更多编码/混合比例/seed。它们不能自动解决以上缺口。已有三个固定增强候选和对应 C 包可以支持接下来的独立确认；最终方案通过确认后，再做同工作负载、同 FPGA/频率/板端计时口径的硬件质量—成本比较。

## 4. 写进论文时哪些成立

可以写“建立了条件误差分析与定点表示对照；发现统计修正收益依赖观测变化和输出编码；给出共享统计实现与明确的精度接受门槛”。实验章节应同时展示强简单基线、负结果、条件回退和数据覆盖，而不是把这轮每个工程动作都列为创新点。

暂时不能写“提出全新平方根算法”“21 维最优”“所有少点场景均稳健”“优于现有实现的板级能效已经成立”，也不能保证仅凭这些实验就满足硕士论文创新要求。论文可以形成清晰的研究链条，但独立确认与同配置实际成本仍决定主结论能写到哪一步。现有板卡有资源余量，约束应来自明确目标，不应虚构“硬件装不下”。

审核方式为当前执行者的源码/数据/方法自审，不冒充第三方独立评审。机械复核、失败记录、旧工件保护及同步结果见 [validation.json](validation.json)。
