## 先读这几条

1. 研究对象可以收窄为：变长、稀疏雷达点簇的统计表示在近似计算下，何时引入有害分类变化；如何在实际硬件成本下保留重要信息。21 维作为旧部署基线保留，不设为必须得到的结论。
2. 已有工作覆盖密度鲁棒性、近似感知训练、混合精度、共享计算成本和特征—分类器联合设计。**这些名词都不能单独作为创新声明。** 本轮未核实到完全相同的任务与方法组合，但检索不穷尽，不能据此宣称“首次”。
3. 更具体的候选问题是：**把统计定义的改变与有限位宽误差分开，并分析它们和点数、形态、分类边界及共享计算成本的交互。** 是否形成独立贡献，取决于简单已有方法对照与实测。
4. 本轮发现形状代理具有信息损失：真实软件 `eig_major/minor` 是协方差特征值，硬件槽位使用极差派生量；增加位宽不能恢复未计算的相关性。不能把它们统一称为“量化误差”。
5. 之前“创新达标”的工程评估不能作为查重结论。工程平台与验证积累保留；创新性需要单独论证，毕业要求仍以学院、导师标准为准。
