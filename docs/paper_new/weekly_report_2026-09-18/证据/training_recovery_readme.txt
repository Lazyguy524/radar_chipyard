## 五分钟结论

1. **checkpoint 与部署参数已对应。** 三个 checkpoint 用完整训练集重新校准后，权重、偏置和尺度与冻结导出一致；21 维也与当前 Chipyard K7 release 一致。原 HDF5 → K7 → 55,516 条测试特征已重建，最终量化输入无差异。
2. **没有发现序列/轨迹/源点文件跨 split，但发现 test 参与选 K。** 历史记录明确比较 test Macro-F1 后选择 K7。既有分数可作为历史开发与部署复现结果，不能继续作为完全未参与选择的独立泛化成绩。
3. **QAT 评价会随 batch 改变。** 量化器在 `eval()` 时仍更新尺度。21 维前 2048 条样本，batch 1024 与 32 有 69 个预测不同；训练集校准并冻结尺度后的同项诊断为 0。最终部署导出另行使用完整训练集校准，不能误判成测试集校准。
4. **K7 不是固定时长的连续七帧。** 它拼接同一序列、传感器、真值轨迹最近 7 次被保留的观测，无时间过期条件。历史 test 窗口跨度中位数 453.939 ms，最大 34.458126 s，14.65% 超过 1 s。需明确输入假设并补有界时间窗对照。
5. **新增了全量部署近似路径的软件评价。** 历史 55,516 条 test 上，原软件特征 + 冻结整数 QMLP 的 Macro-F1 为 0.967020，部署 Feature21 软件镜像 + 同一 QMLP 为 0.963226。镜像与既有 1000 条板测 logits 全部一致。它不是新增 55,516 条板测，也不提供最终性能指标。

这些发现优先影响算法评价协议与论文结论强度。现有硬件正确性、系统集成证据可在原范围内保留；新模型/位流必须重新匹配验证，不能沿用旧数字。
