# 8～36维双向实验：先看结论

**旧23维仍是本轮默认软件候选，新方案未形成足以替换它的综合质量—成本优势。 旧A主基线/B困难备选保持：没有方案同时通过本轮相对23维要求与旧A/B要求。24维单独通过旧A/B要求，但未达到本轮替换23维的增益要求；不能写成所有方案均未过旧门槛。**

完成11组×3种子＝33条新训练，并复用核验过的六个16/23维模型；这轮最低8维，最高36维。综合分最高的是28维：加四分位宽度（97.060%），但选型还要满足全部条件/类别/分组要求以及计算成本偏好，不能只挑最高分。

**往下删：** 8维综合95.780%，两种12维为96.545%和96.476%，15维为96.515%；都低于23维的96.960%。这些具体删组方案在本训练协议下退化，加入更丰富的少数统计量也没有补回全部分数。

**往上加：** 加点数支持码的24维为96.966%，几乎持平；加四分位宽度的28维最高，为97.060%，但一个种子变差、一个少点紧凑组平均下降1.462个百分点，还要增加排序。32/36维也没有稳定替代优势。

**为什么没有继续涨：** 输入只有1～2个点时，本轮新增分位数特征可由已有特征确定，并未增加独立信息。点更多时可以补充内部排序分布，但这次重训的增益不足以抵消局部回退和计算代价。
