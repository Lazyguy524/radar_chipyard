# 算法定义、定标与可执行实现

本轮在隔离目录实现三条路径：旧统计重新定标、局部平移矩统计 Q24、相同统计 Q16；每条保留 seed 7/17。参考代码用于诊断，共享候选用于验证可以单次扫描完成。没有修改旧 Feature21 RTL 的统计含义。

## 1. 输入和输出契约

输入为一个已经完成历史 K7 融合的点簇，1≤N≤511；每点四个 signed Q8.8 值：x、y、补偿径向速度、RCS。坐标使用原始车体坐标语义。训练仍使用原始 min_points=3 后的观测和 GT track；K7 是最近七个保留观测，没有新增真实聚类、轨迹管理、时间到期或跨时刻姿态补偿。

输出仍是 21 个有独立二次幂尺度的 INT8 槽位，接入 21→64→32→2 QMLP。**固定维数只是本轮控制变量**，不是 21 个特征独立、必要或最优的证明。label 0 对应原标签 7/8 的行人及行人组，label 1 对应 0/1/2/3 的车辆相关类；其余类别不在当前二分类任务中。

## 2. 先隔离输出定标

旧硬件镜像对多数统计统一执行 `round_even(raw_q8 × 105 / 65536)`，再限幅到 [−127,127]。新的 `proxy_scaled` 保留其均值分档、跨度代理、范围近似与密度含义，只在输出量化前截取原始统计。

对第 j 个特征，仅从 train 求绝对值的 99.99 百分位 t_j，选择：

`e_j = ceil(log2(max(t_j / 127, 2^-16)))`

`z_j = clip(round_even(f_j / 2^e_j), −127, 127)`

密度槽位已经在旧函数中量化，直接保留原值，e_13=0；不能称全部统计都重新获得无限精度。尺度详见[冻结输出尺度](../../../logs/conditional_statistics_20260916/data/output_scale_exponents.json)。二次幂可以实现为固定移位/舍入，硬件收益须重新实现测量。

逐特征定标允许小尺度统计使用更多 INT8 取值。这一简单解释必须优先与新统计比较，不能把所有提升都归于“更精确的方差”。

## 3. 局部平移与共享矩

在精确实数定义下，以首点 a 为局部原点，d_i=p_i−a，累积四通道一阶和 S 以及 x/y 三个二阶和：

`S_x = Σd_x; S_y = Σd_y; S_v = Σd_v; S_r = Σd_r`

`T_xx = Σd_x²; T_yy = Σd_y²; T_xy = Σd_x d_y`

`mean_x = a_x + S_x/N`

`var_x = T_xx/N − (S_x/N)²`

`cov_xy = T_xy/N − (S_x/N)(S_y/N)`

使用总体矩，分母是 N，不是 N−1；N=1 时方差为 0。这些公式和数据平移本身是已有方法，相关论文与重复边界见[研究复核](00_研究主线复核.md)。研究贡献需要落在雷达条件误差诊断及经过验证的质量—成本取舍上。

整数实现读取一次倒数 `inv=round_even(2^r/N)`，r 为 16 或 24。均值计算多保留四位小数，使用 signed int64 中间值；空间二阶量保留 16 位小数。负对角方差在输出前截零，同时在诊断中统计截零前负值。这个近似不保证量化后的三个数总能组成严格半正定矩阵，当前也不对它求特征值。

首点平移避免在远距离小目标中直接相减两个包含巨大绝对坐标的平方项。它并不消除点云采样不足、物体旋转或首点选择造成的所有误差；当前输入保持原顺序，没有证明有限精度下任意点序置换不变性。

替换关系（从 0 开始的槽号）：

| 槽位 | 旧代理 | 新矩统计 |
| --- | --- | --- |
| 1、2、14、18 | 按 N 分档的移位均值 | 共享倒数与局部平移后的均值 |
| 3、4 | x/y 跨度除 4，作为离散程度代理 | x/y 总体方差 |
| 9 | 用旧均值计算的近似中心距离 | 用新均值计算的同一距离近似 |
| 10 | y 跨度，作为交叉统计代理 | xy 总体协方差 |
| 11、12 | 两轴离散代理的大小排序 | 两个对角方差的大小排序 |

其余槽位保持计数、范围、跨度、速度/RCS 极值与离散代理、旧密度。**11/12 不是特征值，也没有旋转不变性保证**；标准差改为方差后单位不同，必须重定标并匹配训练。多个替换本轮同时发生，只能评价组合表示，不能把收益逐项归因于协方差或精确均值。

## 4. 真正的单遍实现

[shared_candidate.c](shared_candidate.c)在一次点循环中更新原有四通道一阶和、极值和范围，同时按模式增加三个空间乘积累加器。新均值与协方差共用同一组一阶和，簇结束后共用一次倒数查表。参考 [moments.c](moments.c) 与 `extract_all` 为便于多模式诊断有重复扫描，不能用它声称已经实现共享。

[位宽及成本图](../../../logs/conditional_statistics_20260916/shared/cost_graph.json)记录边界：输入 16 位，平移差 17 位，一阶和 signed 26 位，平方和 unsigned 41 位，交叉和 signed 42 位；最坏 N=511 的中间乘积已由 Python 整数证明在 signed int64 范围内。参考 C 使用 int64，不代表最终电路已经裁到这些宽度。

候选省去平方根和特征值求解，但每点新增 3 个空间乘积，不能称免费。三个乘积可以串行复用或并行实现，具体 DSP/周期取舍尚无新测量。删一个特征也不一定省掉上游共享状态：只有没有其他输出使用的计算节点才能删除，因此森林排名不等同于硬件资源排序。

## 5. 如何直接运行

本次已经生成六套完整主机 C 候选，均保留，没有选最高验证分数的 seed 当最终发布版。例如在仓库根目录：

```bash
logs/conditional_statistics_20260916/inference/moment24_seed7/candidate \
  logs/conditional_statistics_20260916/inference/moment24_seed7/example.int16le
```

输入文件是无文件头的 little-endian int16，按 x/y/速度/RCS 顺序，每点 8 字节。程序输出 21 维整数特征、两个整数 logits 和预测类别。空文件、点数超过 511 或长度不是 8 的倍数会被拒绝。程序不负责原始雷达检测、GT track 或 K7 融合。

[candidate_c_bundle.zip](candidate_c_bundle.zip)包含六种模式/seed 的 `candidate.c`、匹配 `params.h`、输入例子与预期 JSON。解压后进入某个模式目录，可不依赖 Python/torch 编译运行：

```bash
gcc -O2 -std=c99 candidate.c -o candidate
./candidate example.int16le
```

这些是主机 C 算法候选，未交叉编译成 Rocket 测试 ELF，未接入 RTL 或 bitstream。旧硬件装载接口不能直接加载“同样 21 维但统计意义已经变化”的新模型。

## 6. 复现实验与冻结要求

执行顺序：`preflight.py → prepare.py → run_training.py → evaluate.py → rf_crosscheck.py → verify_shared.py → audit_findings.py → build_inference.py → make_report.py → finalize.py`。前六阶段已经完成，输出目录拒绝覆盖；重跑需另开目录，不能删除本轮证据后原地重跑。

核心环境为 Python 3.10、NumPy 1.26.4、torch 2.4.1 CPU、h5py 3.11.0；RF 使用隔离 Python 3.10 / scikit-learn 1.5.2 环境；绘图为 matplotlib 3.7.5。[训练前源文件冻结](../../../logs/conditional_statistics_20260916/pre_training_manifest.json)和[最终校验](validation.json)记录来源与预算。`audit_findings.py` 是结果之后补充的归因检查，不冒充预注册的候选筛选结果。
