# 执行反思与失败记录

本文件从正式训练运行时开始记录，后续追加结果；不能回写成全都在训练前确定的设计。

## 数据恢复后

1. 原始少点数量很大：训练 474,582 条，相比保留的 357,780 条更多。旧模型质量只能代表其训练/评价覆盖域，不能把过滤掉的观测默认为不重要。
2. 全量身份、标签与两种特征重建一致；train/validation 轨迹 UUID 无重叠，混合二类标签观测为 0。没有把恢复资料当成另一个独立测试集。
3. 12 个匹配组都有支持，无排除。匹配只限制类别、当前点数和历史数量；距离、序列风格和目标形态仍可能不同，因此组间差值是受控策略比较，不能作纯粹点数因果证明。
4. 历史时间跨度与质心位移可以很大；必须写清没有历史超时或运动对齐。融合形态不是当前真实物体外形。这个范围局限不通过静默修改历史规则来掩盖。

## 正式训练运行期间的审查

- 现有分组辅助代码只为 elongated/intermediate/compact 列出 N×形态；真实少点还有 undefined_low_support。额外检查证明两个真实少点视图都严格满足 `undefined_low_support ⇔ N≤2`。因此其唯一非空交叉单元与已经进入门槛的 N=1～2 组完全相同，不改变门槛结果。汇总阶段补发显式交叉表，保留这一完整性修订记录。
- 两种覆盖共用含真实少点的校准池是预定控制变量；“合成少点训练”不能误写为没有使用过任何真实少点信息。
- 一页主表可显示三种子均值，但模型、最终轮和全部三种子必须都保存。不能选最高分种子代表发布结果。
- 先前 A/B/C 的标准化、类别权重与本轮有所不同，B 对本轮是整个训练策略的比较；本轮 2×2 内部比较才共享这些额外因素。无需改动旧基线重新训练。
