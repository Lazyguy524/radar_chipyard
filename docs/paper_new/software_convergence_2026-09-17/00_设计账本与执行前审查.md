# 软件收敛：设计账本与执行前审查

用户明确暂时不能提供硬件测试资源，要求算法在软件层持续推进到有依据的取舍。2026-09-17 确认兼顾常规/困难条件，并授权纳入真实 1～2 点观测。原研究问题保存在 plan.json；本轮不新增 RTL、SoC、位流、板测或训练服务器任务。

## D01：为什么继续这一轮

前阶段 A/B/C 的差异部分可能来自训练没有覆盖自然少点：357,780 个保留观测参与训练，474,582 个目标类有轨迹少点观测未参与。验证时却评价过 97,734 个自然少点观测。这个缺口值得通过受控数据覆盖对照验证，不能继续只改蒸馏系数。

采用 proxy/均值修正版 × 合成/真实少点覆盖 × 三种子，共十二条。均值修正保留已有中心化计算和倒数精度定义；不新增空间矩、模型结构或损失算法。本轮检验必要性，不预设修正一定获胜。

## D02：执行前实现约定

- 原始划分、多数标签映射与 GT-track 历史不变；少点不进入历史。保留观测的特征必须全量重建一致，自然 validation 的身份与两种已有视图必须一致。
- 357,780 不能被 8 整除。每轮原输入 178,890、少点 89,445；均匀删点与中心保留各 44,722/44,723，奇偶轮交换，两轮合计严格满足比例。这是整数计数实现，不改变用户的混合比例。
- 12 个匹配组为类别×当前点数 1/2×历史数量 0/1～5/6；用训练自然观测的共同支持分布，最大余数法分配每轮少点数量。两个策略的视图位置、类别序列和组数量严格相同，组内带放回抽样。未共同支持组单列。
- 原输入/两种扰动每轮从同一训练行随机排列取互斥区间；合成当前点只抽 1～2 个，前六个保留历史完全相同。这不控制传感器、目标距离等全部差异，不能解释为纯点数因果试验。
- 标准化使用共同期望混合分布；校准行共 16,384，清晰记录原输入/扰动/两种少点的来源。两覆盖策略使用相同标准化、校准身份和类别权重；QAT 隐层尺度由各自训练后的权重在共同校准数据上生成并冻结。
- 既有输出尺度保持，均值倒数精度先用 Q24；固定权重检查 Q12/Q16 后，只有全条件/全种子过数值门槛才降精度，并再次检查方案推广门槛。

## D03：审查风险与处理

当前 21 维、二分类、GT 辅助轨迹和未做跨帧坐标补偿的 K7 是明确任务约定，不是普遍最优或独立感知系统。记录历史时间戳跨度（原始单位）和相对质心位移，不能把累积输入形状直接叫目标物理形状。

原 validation 是开发域；不新增历史 test 评分。比较 B 是整体训练策略比较，标准化/类别权重变化也属于策略差异；真正匹配的真实/合成组用于缩小解释范围。采用多个种子、完整分组和序列 bootstrap，仍不消除既有开发集选择偏差。

新平衡门槛由用户接受的计划单独定义，不能回写前轮失败为成功。异常、负结果和无新方案通过都是有效结果；若存在未解决的数据/实现错误，则不宣称收敛。

本轮审查由同一执行者完成，不称独立审稿。训练前要求身份/历史/数值/抽样预检全部 PASS，先做选择性 Git 备份。训练预算到期后仍完成已有结果整理，不追加训练以挽救假设。
