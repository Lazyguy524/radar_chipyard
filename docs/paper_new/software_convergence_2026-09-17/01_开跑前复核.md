# 开跑前复核

单执行者复核，不称为独立专家审稿。计划在数据恢复前写入 plan.json；本文件在 12 条正式训练前记录。

1. 140 个 train/validation 原始 HDF5 与既有 SHA 一致；113/27 个序列互斥。全量重建核对当前标签、观测身份、点数和两种特征，零差异；未加载历史 test 原始数据。轨迹 UUID 在 train/validation 间零交集，所有历史时间严格早于当前。
2. 恢复 474,582 条训练少点观测；验证保留 80,450 条常规与 97,734 条少点。历史使用同序列/传感器/GT 轨迹前六个保留观测，少点不推进历史；记录时间跨度与位移。K7 没有时间上限且不做坐标对齐，其形态仅指融合输入形态。
3. 真实和合成训练少点的全部 12 个预定分组均有支持，排除数均为 0。合成池对每个原观测固定抽取一份单点和一份两点，训练重采样不创造新物理观测。相同 seed/epoch 的两策略抽样满足相同视图位置、相同常规观测、相同分组配额和逐项标签序列。
4. 357,780 不能被 8 整除，因此四分之一/中心视图的 12.5% 在单轮采用 44,722/44,723，隔轮互换。每轮总访问数严格不变；每两轮比例精确。
5. 156 个边界/随机数值例覆盖 N=1…511 和 Q12/Q16/Q24。独立 Python 均值、舍入量化与 C 镜像一致；训练微步、标准化折叠和 QAT/NumPy 整数推理一致。导出过程继续检查累加界限与 C 逐层结果。
6. 先完成 A/B/C 的 13 条件、点数/形态/交叉/距离/历史分组复核，原始结果位于 baseline_review。以前的扰动训练明显改善少点，但近距离、历史充分组存在回退。数值重建一致是已证事实；这些回退是否来自真实少点覆盖不足，仍是本轮要验证的假设。
7. 参数、输入尺度、最终轮、门槛和预算预先固定。采用相同校准观测池，不要求不同权重模型的隐层尺度数值相等；尺度只由该模型在同一训练池上的激活计算一次，此后冻结。

可确认的是软件镜像与历史资料对应，不能据此确认新域泛化、真实自动跟踪或 FPGA 成本。记录混合原始标签观测并沿用旧多数票，不将多数票变成新增标签真值。正式训练后继续归因、选型和备份，不追加种子或结构。
