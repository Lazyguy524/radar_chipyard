# 后续优先级：先建立可信部署基线

2026-09-16，本轮按六次训练预算结束。固定旧模型下的均值＋协方差修正有正向结果，但匹配重训的两个 seed 中一个略降、一个略升，配对序列区间均跨零。**目前不据此增加协方差硬件或动态精度控制，也不扩大参数搜索。**

这不否定研究问题：点数分档偏差与统计定义损失已有机制依据，部分条件下也有真实标签上的有害翻转。需要收窄的是“只要统计更准确就能改善分类”的假设。尚未证明候选有稳定收益，更没有实际质量—硬件成本优势。

两个阶段还改变了权重/激活数值实现和量化后标准化，不能把阶段间差异完全归因于“训练吸收了误差”。本轮能确认的是：同一 FP32 训练协议内，候选相对当前表示的优势不稳定；部署 QAT 对照仍待建立。

## 1. 利用缓存做的一项低成本补查

在训练结束后，仅统计已有 validation 特征数组，没有新模型、新干预模式或新数据。见 [profile_quantized_inputs.py](profile_quantized_inputs.py)、[CSV](quantized_input_profile.csv)和[JSON](quantized_input_profile.json)。该分析是**事后描述，不是预注册的确认性证据**。

采用当前统一输出量化算式时，准确统计表示中的：

- 方位角跨度约 **99.50%** 为零，仅有 2 个不同整数值；旧硬件此槽位采用 y 极差，两者统计含义不同。
- 协方差次特征值约 **97.82%** 为零；这是数值量化后的观测，不能据此假定恢复该维一定有分类收益。
- 协方差主特征值有 123 个不同整数值，当前代理只有 8 个；信息容量变化并未在本轮两 seed 对照中转化为稳定优势。

本轮训练在量化后标准化，无法恢复已经合并到同一个 INT8 值的差异。因此“匹配重训未发现优势”不能证明准确统计永远无用，也不能证明无限精度下两种表示等价。

另一方面，几乎全零的特征可能本来就不重要；该现象不自动证明它是准确率瓶颈。逐特征缩放、混合精度已有大量工作，下一轮应将它们作为简单对照，不能直接冠以新方法。

## 2. 下一轮建议的唯一优先任务

建立**当前硬件镜像匹配的、尺度冻结的 INT8 训练与导出基线**，先解决旧 QAT 在 eval 时 observer 仍变化的问题，并检验输入标准化能否通过明确的定点设计或权重折叠接入。这个任务有部署价值，也能防止后续近似研究拿弱基线做比较；它本身不是本论文已成立的创新点。

完成这一基线后，再决定是否需要一个“准确统计＋训练集确定的逐特征定标”对照，区分统计信息损失与统一尺度掩盖信息。现有数据、缓存和脚本可以复用，不应再扫描候选网络、增加 LSTM 或开始新的 bitstream。

如果简单定标/匹配训练已经达到相同质量，则保留简单方案；若仍出现稳定、跨序列的条件性损害，再考虑少量共享统计原语和精度选择。任何新增算子都应有明确可测收益，不能以 MAC 数或特征维数下降替代实际成本。

## 3. 下次启动前应冻结的内容

1. 训练/验证以及确未参与开发的最终评价来源；历史 test 不会因为重命名或随机重划分而恢复独立性。
   当前簇与 K7 历史依据数据集标注轨迹构造，不能据此宣称在线目标检测、聚类和跟踪系统的端到端识别效果。
2. 不改变 K7 时间信息的对照，或将时间窗口修正独立成另一个实验因素。
3. 输入/权重/激活尺度的校准来源、冻结时点、整数参考和导出一致性。
4. 至多两个基线的先行小样本检查、明确的时间上限与阶段门槛；扩大之前先判断是否产生新信息。
5. 后续硬件比较匹配 bitstream、ELF、权重、数据、频率、批大小和测量窗口。没有上板结果就不升级最终性能指标。

本轮的合理成果是：确认部分机制、排除未经公平训练验证的乐观解释，并保存可复用的诊断链。它为研究选方向提供证据，不是已完成的新算法或新硬件实现。
