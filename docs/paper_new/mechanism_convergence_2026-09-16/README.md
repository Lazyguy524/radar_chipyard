# 点数、形态与量化机制：35 条训练后的收敛判断

2026-09-16。按照“持续测，多获得数据后再判断”的要求，完成 **35 条固定轮数训练、11 种输入条件、五档倒数精度、97,734 条真实被过滤观测审计**。每条训练使用完整 357,780 条 train；训练共 40.86 分钟，2 个 CPU 线程，无 GPU/服务器任务。旧论文包、权重、RTL、位流均保留。

**目前最有依据的方向是：以逐特征定标和条件覆盖训练作为强基线，再判断是否确有必要增加统计和算术成本。更精确的均值、二阶矩与输出编码尚未形成全面优于简单基线的方案。** 这不是停止研究，而是结束“多算一点应该更好”的无依据扩展，转向有明确收益组和受损组的约束问题。

建议先用十分钟读以下两篇，再查表：

1. [评审与收敛决定](03_评审与收敛决定.md)：回答得到什么认识、保留哪些候选、哪些假设被削弱、后面还缺什么。
2. [分组收益与回退](05_分组收益与回退.md)：同样保留一半点，保留位置不同导致明显差异；增强对无历史少点组改善，同时在部分近距离/历史充分组回退。
3. [完整结果与图表](02_结果与所得认识.md)：五 seed 机制拆分、共同三 seed 的训练/编码比较、零值比例、精度门槛和真实覆盖。
4. [方法、计划审查与复现约束](01_方法与计划审查.md)、[C 实现和使用](04_实现与复现.md)。

最容易误读的几个结论：

- 原代理的均值分档确有数值偏差，但不是所有分类错误都由这个偏差造成。只修正均值在中心保留一半时有改善，在均匀减点时没有稳定优势。
- 原矩统计的 x/y 方差输出有 67.14%/91.20% 被 INT8 定标映成零。开平方后降到 0.54%/1.15%，分类稳定性却未全面改善；保留更多数值信息不等于保留更多任务所需信息。
- 原代理＋扰动训练，在相同三个 seed 下，均匀保留四分之一的 Macro-F1 从 95.6961% 到 97.0365%，中心保留一半从 95.2759% 到 97.0093%。但真实少点观测中近距离组从 97.2008% 到 96.3038%，必须同时报告。
- 粗矩输出下 Q12 倒数通过的门槛，换成较细线性或开平方输出后并非所有 seed 都通过；Q16 在本轮所测表示中通过。这里是倒数小数位，不是把全部数据或累加器改成 16 位。

研究对象仍是原 GT-track K7 二分类，固定 21 槽位用于控制变量，**不声称 21 维最优**。评价是熟悉的 validation 序列，不能当新独立测试；模拟删点不是标定过的遮挡。当前没有新 RTL、位流或板测，尚未证明最终硬件质量—成本优势。
