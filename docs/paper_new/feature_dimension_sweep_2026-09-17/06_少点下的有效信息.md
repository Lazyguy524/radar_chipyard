# 36维不等于36份独立信息

这轮可以在训练分数之外得到一个明确的数学结论：新增分位特征在少点时会成为旧特征的确定性变换，不能因为分类分数变化就说“看到了更细的形状”。

- N=1：本轮12个分位描述全为0。
- N=2：四个分位宽度只能为0或64，与对应旧范围归一化方差的0或127一一对应；不对称和中位位置都是0。因此，在已包含点数编码的24维之后增加这12维，并不为两点输入增加新信息。
- N=3：四个分位宽度仍由旧方差是否为0决定；新中位位置四维又恰为新不对称四维的负数。因此32→36维对三点输入也只是重复编码。

推导直接来自固定分位插值定义。已对全部13个真实/扰动视图中存在的N1/N2/N3输入逐整数检查通过，证据见[信息依赖核对](../../../logs/feature_dimension_sweep_20260917/explanation/information_dependencies.json)。它是表示恒等关系，不是分类性能推断。

因此，若大模型在这些切片上的分数改变，解释应考虑其他点数样本参与共享训练、重参数化、量化尺度和优化，而不能把全部变化归为这些切片新增了独立几何信息。N更多时，分位数可能记录旧矩统计丢失的内部排序信息，是否值得排序代价仍须看匹配训练。

本轮的17维点数方案属于机制对照，冻结选型对它采用“新增信息相对23维须有足够增益”的保守条件；即使未获选，也不能推断所有17维都不可行。独立公开的质量—成本非支配集合用于保留这种潜在简化线索，不事后改变门槛。

另一个无标签编码反例：把同一个点[1m, 0m, 0m/s, RCS输入10]重复一次，N=1与N=2的旧23维编码可以完全相同，而新支持码分别是127和64，见[实际C输出](../../../logs/feature_dimension_sweep_20260917/support_encoding_example.json)。它证明原表示可能丢失该点数区别，不证明重复点提供了独立观测或分类收益。
