# 分位数不是唯一一种定义

Hyndman和Fan讨论了软件中的不同样本分位定义及其性质；论文信息为The American Statistician 50(4), 361–365 (1996)。作者页面还保留了后续勘误，不能只看旧表格便声称某种定义满足全部理想性质。[作者原始资料](https://robjhyndman.com/publications/quantiles/)。

R官方文档给出的type 7插值位置与本轮固定的零基位置(n−1)p一致；文档也明确作者推荐的是type 8，不能把“常用默认值”说成作者推荐的最优估计。本轮选择type 7是为了固定定义和以四倍整数准确实现，并未比较九种定义或声称分布无关的最佳估计。[R官方分位数文档](https://stat.ethz.ch/R-manual/R-devel/library/stats/html/quantile.html)。

这份核对在训练期间补充，没有改动已冻结公式、数据或训练。N=1/2/3的退化、重复点效应与INT8依赖关系由本仓库针对该明确公式推导并核验，不外推成所有分位定义共有的性质。文献支持方法界定，不替代雷达分类收益证据，也不构成统计量本身的原创性。
