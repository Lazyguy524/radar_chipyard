# 双向维度实验：先确定问题与范围

用户希望高于23维和低于16维都继续测试。原研究问题不变：点数/形态变化中的近似误差、表示、精度与共享成本。维度不是单向减少目标，也不是越多越好；本轮不改变数据划分、历史、训练预算分配、损失、隐藏层或最终轮选择。

小模型：8维保留N、x/y代理均值、x/y跨度、速度代理均值、RCS代理均值/跨度；12维代理加入距离极值、速度跨度和RCS最大值。另由8维补4个速度/RCS分布量成12维，补完整7个分布量成15维。这些是按物理信息组预设的有限子集，不是已证明的最佳8/12/15维；同维12方案用于区分“数量相同但信息不同”。

点数对照：在旧16和旧23上只补一个127/N的INT8编码，分别成17和24维。N指送入特征核的总点数，含既有历史；N=1/2分别编码127/64，旨在解开旧点数N/4编码混淆少点的问题，不宣称对1～511所有点数都精确。不得把总点数当作当前单帧点数。

上扩：24维上增加四通道的四分位间距/极差，或四分位不对称度，分别为28维；两组都加为32维，再补四通道中位数在范围内的位置为36维。再设24维加12个重复旧输入的36维对照。分位数使用排序后线性插值的固定定义、解析值域和ties-to-even量化，不用开发集拟合新尺度。范围归一化仍受极端点影响，不称所有新量都具备抗离群保证。

旧16/23的三种子模型在SHA和输入/预测一致性检查后复用，不重复训练不变方案。11个新方案×种子7/17/37，共33条，每条固定20轮FP＋60轮QAT、最终轮。保持同一自然少点覆盖、357780次访问/轮、原校准身份与第一层标准化折叠。新增列零初始化；剪掉输入无法保持完整基线初始函数，匹配扩展组则可以。

用户本轮要求扩大实验，训练上限明确扩大到60分钟（预计约42分钟）；准备30分钟、评价/C打包30分钟，两CPU线程、无GPU/服务器/硬件、产物≤4GiB。只做固定33条，不临时加种子、阈值、删维组合或重训救分。数值/身份问题先停依赖阶段，保留失败证据；训练完成后继续整理，不以停止训练代替收敛解释。

全13条件、每类指标、点数/形态/距离/历史与交叉组、错误修复/新增、配对27完整序列2000次区间全部公开。相对旧23：常规每seed损失≤0.2pp、各条件平均F1损失≤0.3pp、各类召回损失≤0.5pp；支持充分组（三序列/百条/两类）三个seed都退步且平均>1pp则拒绝。小模型综合平均损失≤0.1pp才可作为简化候选；扩展模型须综合增益≥0.1pp且三个seed都正。分位数组还须对24维点数对照满足同样增益；完整36维还须超过等维冗余36对照，防止把点数/参数效应冒充新增分布信息。

在通过候选及旧23兜底中，综合距最高0.1pp以内，按无排序、每点乘积少、网络小、有理数量化少的顺序作透明简洁性选择；这不是实测时延优化。旧A/B推广门槛独立且不放宽。未过则保留A主/B备，软件候选与硬件支持分开。另公开质量/成本非支配集合，不将所有代价压成伪造的单一FPGA指标。

重点追踪上轮116条/19序列的少点紧凑组，但它不是新增选择门槛，也不新增对该组的样本加权。只凭这一组变好不能选型。序列区间仅为开发域稳定性描述，不是独立显著性；分位数和统计量是已有工具，不能包装成未经证实的原创算法。
